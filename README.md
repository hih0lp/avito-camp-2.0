# Ориентация кропа с текстом (0° / 180°)

Подробный разбор с кодом и графиками — в **`solution.ipynb`**. Файл для отправки — **`submission.csv`**.

## Результат

| вариант | модели | лидерборд (1 − Brier) | параметров | мс на кроп* |
|---|---|---|---|---|
| `fast` | textline + распознаватель кириллицы | 0.99228 | ~2.25 млн | ~325 |
| `accurate` | + распознаватель английского + своя CNN | 0.99422 | ~4.6 млн | ~684 |
| **`cascade` (итог)** | `fast`; для неуверенных кропов (6%) — `accurate` | **0.99422** | ~4.6 млн | **~347** |

\* один поток CPU (Apple M5), с учётом прогона на кропе и на его перевороте.

## Подход

* **OCR как детектор ориентации.** Распознаватель уверенно читает нормальный текст и плохо — перевёрнутый.
  Каждая модель запускается на кропе `x` и на `rot180(x)`, признак — разность ответов.
* **Модели:** PaddleOCR `PP-LCNet_x0_25_textline_ori`, `cyrillic_PP-OCRv5_mobile_rec`, `en_PP-OCRv5_mobile_rec`
  (готовые, Apache-2.0) и своя CNN на 390 тыс. параметров (4 свёрточных блока, обучена на открытых данных).
* **Симметрия:** признаки антисимметричны, поверх — логистическая регрессия без свободного члена,
  поэтому p(rot180(x)) = 1 − p(x). CNN устроена так же: `logit = g(x) − g(rot180(x))`.
* **Каскад:** если `fast` уверен (`max(p, 1 − p) ≥ 0.95`), берём его ответ, иначе — ответ `accurate`.

## Валидация

Тестовые картинки для обучения не использовались.
* **Синтетика** (основная): 3000 кропов с русским/латинским текстом, 203 шрифта, фоны, наклон, blur, JPEG;
  половина перевёрнута. Метрики — out-of-fold (5 фолдов). Хорошо предсказала лидерборд:
  0.9931 → 0.9923, 0.9944 → 0.9942.
* **Реальные кропы** (проверка): 5044 кропа из Union14M, номеров машин и рукописи; половина перевёрнута.

CNN обучена на `Union14M-L-STR` (MIT, 471 тыс. реальных кропов) и `OCR-Cyrillic-Printed-6/10`
(600 тыс. синтетических кропов; лицензия в карточке не указана). Все датасеты — с HuggingFace.

## Что пробовали

| что | итог |
|---|---|
| только `textline_ori` + TTA + EM-поправка доли перевёрнутых | 0.946 на синтетике — плохо знает кириллицу |
| docTR, EasyOCR, PaddleOCR `cyrillic_v3`, `eslav_v5` | слабее или без прироста |
| символьная языковая модель по распознанному тексту | без прироста |
| предобученная MobileNetV3 вместо своей CNN | в пределах шума, больше параметров |
| градиентный бустинг вместо регрессии | не лучше, хуже на реальных кропах |
| калибровка на синтетике + реальных кропах | хуже: реальные кропы сложнее теста |
| каскад «CNN → ансамбль» | хуже, чем каскад от `fast` |

## Запуск

Python 3.10–3.12, любая ОС; GPU не обязателен.
```bash
python -m venv .venv
source .venv/bin/activate          # Windows: .venv\Scripts\activate
pip install -r requirements.txt
python -m ipykernel install --user --name avito-camp
```
Положите данные из задания в корень проекта:
```
solution.ipynb
sample_submission.csv
test/images/test_00000.png ... test_19999.png
```
Откройте `solution.ipynb`, выберите ядро `avito-camp` и нажмите **Run All**. По умолчанию используются сохранённые выходы моделей (2–5 минут);
`RECOMPUTE_FEATURES = True` пересчитывает всё на тестовых картинках (~1 ч на CPU). Seed везде 42.

Ноутбук записывает **`submission.csv`** (каскад). Какой вариант считать итоговым — флаг `FINAL_VARIANT`
в разделе 0: `cascade`, `fast` или `accurate`.

## Структура

* `solution.ipynb` — решение; `submission.csv` — файл для отправки
* `src/` — модули: `io_utils.py` (чтение данных), `synth.py` (генератор синтетики), `methods.py` (обёртки готовых
  моделей), `ensemble.py` (признаки, калибровка, каскад), `textlm.py`, `model.py` и `data.py` (CNN), `packed.py`
* `scripts/` — запускаемые скрипты: `compute_features.py`, `train.py`, `predict.py`, `pack_data.py`,
  `make_calib_set.py`, `make_synth_val.py`
* `features/` — сохранённые выходы моделей, `checkpoints/` — веса CNN
* `data/synth_val/labels.csv` — синтетическая валидация (сами картинки не нужны: калибровка учится на готовых
  выходах моделей из `features/`; пересоздать их можно через `scripts/make_synth_val.py`),
  `data/calib_val/labels.csv` — метки реальной выборки, `data/textlm_4gram.pkl` — кэш языковой модели

Внешних датасетов (~5 ГБ) и тестовых картинок здесь нет: датасеты скачиваются ссылками из ноутбука
(нужны только для переобучения CNN), картинки — из архива задания.
